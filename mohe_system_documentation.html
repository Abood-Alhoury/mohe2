1 الملخص التنفيذي والهدف الاستراتيجي من المنظومة
Executive Summary

المنظومة الوطنية لمعادلة الشهادات والتعادل الأكاديمي هي منصة سيادية متكاملة أطلقتها وزارة التعليم العالي والبحث العلمي (مجلس التعليم العالي) في الجمهورية العربية السورية. تهدف المنظومة إلى حوكمة ورقمنة إجراءات معادلة المؤهلات العليا (الماجستير والدكتوراه) ومنح تراخيص السماح بالتدريس لأعضاء الهيئات التدريسية والتعليمية المرشحين للعمل في الجامعات الخاصة السورية، استناداً إلى اللائحة التنفيذية والتعميم الوزاري رقم (150 / ص).

🏛️ الحوكمة ومنع التكرار والتزوير
ربط كل مرشح برقم وطني فريد (11 خانة) مع فحص فوري لمنع تكرار الإضبارة بين الجامعات، وإلزامية التدقيق للأصول وتصديقات الخارجية والعدل.
⚡ أتمتة اللجان والمقابلات
جدولة مركزية موحدة لمواعيد المقابلات الشفهية والعملية، وتوثيق قرارات اللجنة العامة ولجنة الإنتاج العلمي، والتنبيه التلقائي للجامعات.
📑 إصدار القرارات والأرشيف الموحد
توليد قرارات وزارية رسمية بصيغة PDF، ودمج الوثائق المتعددة (معادلة + أهلية) بملف واحد سلس، وتنزيل الحزم كاملة بصيغة ZIP.
نطاق العمل الرئيسي: يخدم النظام طرفين رئيسيين: (1) أمانة مجلس التعليم العالي واللجان المتخصصة كإدارة مركزية عليا، و (2) إدارات شؤون العاملين والعمداء في الجامعات السورية الخاصة كمؤسسات مقدمة ومتابعة للطلبات.
2 البنية التقنية ومعمارية النظام (Technology Stack)
Architecture
الطبقة التقنية التقنيات المستخدمة الدور الوظيفي والمسؤولية
Backend Framework Laravel 12.x / PHP 8.2+ معمارية MVC متقدمة، معالجة المسارات، بوابات الصلاحيات (Gate & Middleware)، وبناة الاستعلامات المخصصة.
Frontend UI & Styling Blade Templates + Tailwind CSS v4 + Bootstrap 5.3 RTL واجهات عصرية متجاوبة بالكامل RTL، مكونات Bento UI، وتدرجات الهوية الملكية (Navy #0e1e38 & Gold #c59b27).
Client-side Reactivity Alpine.js + Vanilla JS (ES6+) تحكم القوائم الجانبية القابلة للطي، التصفية الفورية للبيانات في الجداول، والتحقق التفاعلي من الحقول والمرفقات.
Document Processing Barryvdh DomPDF + ArPHP + FPDI / FPDF توليد مذكرات العرض والقرارات بصيغة PDF، معالجة الحروف العربية والاتجاهات (BiDi Engine)، ودمج ملفات PDF المتعددة بحزمة واحدة.
Database & Storage MySQL / SQLite + Laravel Storage (Public Disk) تخزين العلاقات المتشعبة، مع حماية الملفات وتصنيف المرفقات في مسارات محددة storage/app/public/attachments/{app_id}.
3 بوابات النظام وصلاحيات المستخدمين (Role-Based Portals)
RBAC System
👑 لوحة تحكم أمانة المجلس (Admin Portal) role: admin

المسار الأساسي: /admin/*

  • Dashboard (/admin/dashboard): إحصائيات فورية وتدفق المعاملات.
  • Applications (/admin/applications): استعراض كافة المعاملات وفرزها وتدقيقها.
  • Committee (/admin/committee): شؤون وقرارات اللجنة العامة والبت بالمؤهلات الخارجية.
  • Interviews (/admin/interviews): منظومة جدولة وتثبيت مواعيد المقابلات ورصد نتائج الأهلية.
  • Scientific Production (/admin/scientific-production): إدارة معاملات الدكتوراه المحالة للإنتاج العلمي.
  • Decisions (/admin/decisions/*): إصدار القرارات الوزارية بحسب المسار الأكاديمي (نظري، تطبيقي، دكتوراه، سماح تدريس).
  • Central Archive (/admin/archive): الأرشيف المركزي الموثق والبحث المتقدم بالقرارات الصادرة.
  • Edit Application (/admin/applications/{id}/edit): تعديل إضبارة المرشح وبيانات الجامعة والشهادات والمرفقات.
  • Settings (/admin/settings): إدارة الجامعات، قفل الموقع، والدول والمؤهلات.
🎓 بوابة الجامعات الخاصة (University Portal) role: university

المسار الأساسي: /university/*

  • Dashboard (/university/dashboard): كروت KPI للمعاملات، إجراءات سريعة، وآخر المعاملات.
  • Application Wizards (/university/apply/*): معالجات تقديم خطوة بخطوة للمسارات الخمسة (ماجستير داخلي، ماجستير خارجي، دكتوراه سورية، دكتوراه خارجية، سماح تدريس).
  • Saved Drafts (/university/drafts): إدارة ومتابعة المسودات المحفوظة قبل الإرسال النهائي بنمط Bento UI.
  • Candidate Lookup (/university/candidate/lookup): استعلام فوري بالرقم الوطني لمنع تكرار الإضبارة واسترجاع البيانات.
  • Required Documents (/university/required-documents): الدليل الرقمي التفاعلي للائحة التنفيذية والأوراق المطلوبة.
  • Messages Hub (/university/messages): التراسل الفوري وتلقي التنبيهات الرسمية بمواعيد المقابلات ونتائج اللجان.
4 المسارات الأكاديمية الخمسة وقواعد العمل (The 5 Academic Tracks)
Business Rules
المسار الأكاديمي الرسم المالي متطلبات وشروط الاعتماد محطة البت الأساسية نوع القرار النهائي
1. ماجستير سوري
داخلي - نظري/تطبيقي		 100,000 ل.س شهادة الإجازة + مصدقة الماجستير + وثيقة التواريخ وقرارات المجلس + الأطروحة. التدقيق الإداري ➔ المقابلة الشفهية (للنظري) لإثبات الأهلية التدريسية. قرار معادلة وأهلية تدريسية (أو تعادل مباشر للتطبيقي).
2. ماجستير غير سوري
خارجي - نظري/تطبيقي		 100,000 ل.س شهادات أصلية مصدقة من الخارجية والعدل + إثبات الإقامة وجوازات السفر + ترجمة محلفة. اللجنة العامة:
• نظري: اشتراط خبرة سنتين + بحث ➔ مقابلة.
• تطبيقي: دون خبرة ➔ بدون مقابلة (هيئة فنية). 		• نظري: قرار تعادل + أهلية.
• تطبيقي: قرار تعادل تطبيقي وحيد.
3. دكتوراه سورية
داخلي حكومي/خاص		 125,000 ل.س مصدقة الإجازة + مصدقة الماجستير + مصدقة الدكتوراه + ملخص الأطروحة. التدقيق الإداري ➔ المقابلة الشفهية والعملية لإثبات الأهلية التدريسية. قرار تعادل درجة الدكتوراه + قرار ثبوت الأهلية التدريسية (ورقتان مدمجتان).
4. دكتوراه غير سورية
خارجية + إنتاج علمي		 125,000 ل.س 3 نسخ أطروحة مطبوعة + 3 ملخصات عربية ≥ 25 صفحة + قرص ليزري + تصديقات الخارجية. اللجنة العامة ➔ لجنة الإنتاج العلمي (فحص الأطروحة) ➔ المقابلة الشفهية. قرار تعادل درجة الدكتوراه + قرار ثبوت الأهلية التدريسية (ورقتان مدمجتان).
5. عضو هيئة تدريسية حكومية
سماح بالتدريس		 125,000 ل.س بيان وضع وظيفي رسمي يثبت رتبة (مدرس / أستاذ مساعد / أستاذ) بجامعة حكومية سورية ساري المفعول. تدقيق بيان الوضع وموافقة الجامعة الأم ➔ لا يحتاج لمعادلة ولا لجنة علمية. قرار وزاري بالسماح بالتدريس بالجامعة الخاصة (ورقة واحدة).

🔄 آلية التخفيض التلقائي (Downgrade)
في الماجستير الخارجي، إذا قررت اللجنة العامة عدم كفاية الخبرة النقدية، يتم تحويل مسار الطلب تلقائياً من (نظري) إلى (تطبيقي)، ونقله مباشرة إلى (بانتظار إصدار القرار) متجاوزاً المقابلة.
📅 الجدولة والإشعارات الفورية
عند تحديد موعد المقابلة في شاشة المقابلات، يقوم النظام تلقائياً بإنشاء رسالة إشعار رسمية في جدول application_messages موجهة لجامعة المرشح بتفاصيل التاريخ والوقت والقاعة.
⛔ التسجيل المسبب للرفض
في حال رفض أي معاملة من قبل اللجنة العامة أو في المقابلة، يُلزم النظام المستخدم بإدخال سبب الرفض التفصيلي، ويتحول الطلب إلى (مرفوض) مع حفظ سجل التدقيق بالكامل.

7 هندسة توليد الوثائق والدمج الذكي (Document & PDF Engine)
PDF Processing
📄 مذكرة العرض الرسمية (Mozhakkara)
وثيقة وزارية تفصيلية تستعرض السيرة الأكاديمية الكاملة للمرشح من الشهادة الثانوية وحتى الدكتوراه، تشمل التواريخ وتطابق التخصصات والمقررات والمشرفين وملاحظات أمانة المجلس.
📜 القرارات الوزارية الرسمية المؤتمتة
توليد نصوص القرارات الوزارية بصيغ قانونية معتمدة، مع وضع أرقام المراسيم وتواريخ الجلسات والتوقيعات الرسمية، وتصديرها بصيغة PDF فور الاعتماد.
الدمج الذكي والتحميل الموحد (Smart PDF Bundling): تم برمجة دالة downloadBundle($id) و viewAttachment($id, $type) باستخدام مكتبة FPDI / PDFMerger:
  • إذا كان الطلب يتضمن قرارين (مثل الدكتوراه: قرار تعادل + قرار أهلية): يدمجهما النظام تلقائياً داخل ملف PDF واحد متصل عند النقر على أيقونة التنزيل.
  • إذا كان الطلب يتضمن قراراً واحداً (مثل الماجستير التطبيقي أو السماح بالتدريس): يتم فتح أو تنزيل ملف الـ PDF المعتمد مباشرة دون دمج.
  • توفير خيار لتنزيل الحزمة الكاملة (Zip Archive) المتضمنة كافة وثائق ومرفقات المرشح بضغطة زر واحدة.
